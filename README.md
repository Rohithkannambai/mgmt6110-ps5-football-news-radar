# Football News Radar — MGMT6110 Problem Set 5

Individual submission by Rohith Kanna for MGMT6110 Human-AI Collaboration.

Football News Radar is a Zapier agent with one trigger and one action. It monitors the Sky Sports, BBC Sport and The Guardian football RSS feeds and creates a record in Zapier Tables for each new item.

The submission page extends our Week 7 group map, places the agent in **AI alone, with checks**, documents three verified runs, and shows the deliberate tricky-case test and successful repair.

- Live page: https://mgmt6110-ps5-football-news-radar.vercel.app/
- Quadrant: AI alone, with checks (bottom left)
- Direct cost: S$0 using Zapier’s free plan
